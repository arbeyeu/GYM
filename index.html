Cloud & Local Hosting Guide

Because IRONCORE is an enterprise Java 17 Spring Boot backend with embedded Tomcat and H2/MySQL, it requires a Java container host rather than a serverless frontend router.

Render (1-Click Free)

Connect your GitHub repo to Render as a Web Service. The included render.yaml and Dockerfile configure everything automatically.

Build: Dockerfile
Port: 8080

Railway

Select "Deploy from GitHub Repo" on Railway. It auto-detects the multi-stage Dockerfile and deploys in under 2 minutes.

railway up

Local Execution

Run on Windows with the included zero-friction portable JDK 17 runner:

.\run.ps1
